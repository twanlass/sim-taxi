# Clip provenance

One row per file in this folder. `npm run check` fails on a clip with no row, and on a row with no
clip, because audio whose licence nobody wrote down cannot ship in an App Store build.

`Source` is a URL somebody else can check. `Licence` is an SPDX identifier where one exists
(`CC0-1.0`, `CC-BY-4.0`) or a named grant where it does not ("commissioned, work for hire").
